# 烈焰突袭 (BlazeRush)

霓虹肉鸽竖屏动作游戏：保留极简 **移动 / 射击 / 必杀** 三键操作，融入 3 架可选战机、波次三选一强化与流派共鸣、掉落补给及 3 种轮换领主战。

## 玩法与特性（v2.1.0）

- **真机全面屏手感**：`expand` 全面屏自适应（自动避让顶部刘海与底部手势条）、**左手动态跟随虚拟摇杆**、可选**「自动射击」开关**（局内/标题/暂停一键切换）、低血量红光心跳预警
- **3 架可选初始战机**：标题页一键切换 **烈焰先锋**（均衡突击）、**雷霆散射**（天生双发 + 移速）、**星核重炮**（天生穿透 + 高暴击 + 快充能）
- **波次三选一 + 4 大流派共鸣 + 免费刷新**：12 种强化叠出 **雷火风暴**（链式闪电）、**聚能死光**（穿透增伤必暴）、**灼烧余震**（必杀留场火域）、**圣盾回响**（碎盾清弹震荡波 + 10 杀回血）；每波提供 1 次免费刷新
- **3 种轮换领主 Boss**（每 5 波登场）：**烈焰领主**（第 5 波）→ **裂空双子**（第 10 波，双 Boss 联动、击杀其一另一只狂暴）→ **星穹裁决者**（第 15 波，螺旋弹幕 + 四向脉冲 + 召唤护卫）
- **战斗掉落补给**：能量晶核、生命结晶、烈焰过载核心（5.5 秒狂暴射速 + 额外弹丸）
- **完善控制**：独立开关音乐 / 音效 / 震动 / 自动射击；安卓返回键与 `Esc` 暂停；标题页右上角显示当前版本并自动检查 GitHub Releases 新版本
- 桌面调试：`WASD` 移动，`空格/J` 射击，`K/Shift` 必杀，`Esc` 暂停

## 要求

- Godot **4.7.x**
- Android 导出见 [`docs/android-signing.md`](docs/android-signing.md)

## 发布与导出 APK

正式 APK 通过推送与版本号一致的标签发布（例如 `v2.1.0`）。GitHub Actions 会用仓库 Secrets 里的同一把项目密钥签名，并挂到 [Releases](https://github.com/JeffGu98/BlazeRush/releases)。流程和密钥备份说明见 [`docs/android-signing.md`](docs/android-signing.md)。不要把密钥提交进本仓库。

本机构建：

```bash
./tools/export_android.sh
```

产物默认：`build/BlazeRush-<version>.apk`（arm64-v8a）。

## 自测

```bash
godot --headless --path . -s res://tools/selftest.gd
```
